# AutoPi 零基础使用教程

这份教程面向第一次使用本地 AI Agent 的 Windows 用户。全程不需要安装 Node.js，也不需要输入命令。

## 1. 下载正确的文件

1. 打开 [AutoPi 最新正式版本](https://github.com/shoelace66/AutoPi/releases/latest)。
2. 在 Assets 区域下载 `AutoPi-0.84.1-win-x64.zip`。
3. 同时下载同名的 `.sha256` 文件可以校验文件是否完整；这一步推荐但不是必需。

当前桌面正式包支持 64 位 Windows 10/11。

## 2. 解压并启动

1. 在下载目录找到 ZIP。
2. 右键它，选择“全部解压缩”。
3. 打开解压后的 `AutoPi-0.84.1-win-x64` 文件夹。
4. 双击 `AutoPi.exe`。

请不要直接在压缩包预览窗口中双击程序。AutoPi 需要和旁边的 `resources` 目录一起运行。

如果 Windows SmartScreen 提示“已保护你的电脑”，先确认文件来自本仓库的正式 Release；核对后选择“更多信息”，再选择“仍要运行”。当前社区版本没有商业代码签名，因此第一次下载时可能出现这个提示。

## 3. 第一次打开工作区

1. 点击“打开文件夹”。
2. 选择一个你希望 AutoPi 协助处理的目录，例如自己的代码项目、文档目录或一个新建的空文件夹。
3. AutoPi 会把这个目录作为当前工作区，并在其中读取文件、运行命令和保存你授权的修改。

建议第一次先选择一个可备份、没有敏感信息的测试目录。AutoPi 不是安全沙箱，它拥有与你当前 Windows 账户相同的文件和进程权限。

## 4. 配置模型

AutoPi 本身不附带云模型额度。第一次对话前，需要在设置或模型选择界面选择服务商，并按提示配置该服务商的 API Key 或登录信息。

- API Key 应从对应模型服务商的官方控制台创建。
- 不要把 Key 粘贴到聊天内容、项目文件、截图或 Issue 中。
- 如果模型列表为空，重新打开设置并检查服务商配置，然后新建或重新进入会话。

完成后选择一个模型，就可以开始对话。

## 5. 发出第一个任务

把需求说清楚即可，不需要学习固定命令。比如：

```text
先只检查这个项目，告诉我如何启动、当前有哪些问题，不要修改文件。
```

确认它理解正确后，可以继续：

```text
修复刚才发现的问题，完成后运行测试，并用简单语言告诉我改了什么。
```

对重要项目，建议使用 Git 或先备份。涉及删除、覆盖、大量移动文件、安装软件、发布内容或使用凭据时，请仔细核对操作范围。

## 6. 使用 Auto 能力

AutoPi 可以在当前进程中等待条件满足后继续同一会话。例如：

```text
运行构建。如果进程还没有结束，就等待它；结束后检查错误并继续修复。
```

```text
等 report.json 被修改后读取它，然后生成一份中文总结。
```

```text
20 分钟后提醒我检查部署结果，并读取 logs 目录里的最新日志。
```

等待期间仍可继续和 AutoPi 对话。不再需要的等待任务可以直接让 AutoPi 取消。请注意：完全退出 AutoPi 后，尚未触发的等待任务目前不会自动恢复。

## 7. 常用界面功能

- 左上角 AutoPi 图标：显示当前品牌主题。
- 右上角太阳/月亮按钮：首页直接切换 AutoPi Dark 与 AutoPi Light。
- 工作区与会话列表：回到以前的工作目录和对话。
- 终端：查看 AutoPi 运行的本地命令。
- 设置：配置模型、语言、主题和“登录 Windows 时启动”等选项。

## 8. 可选的命令行入口

普通用户不需要使用这些文件。熟悉终端的用户可在解压目录中运行：

```powershell
.\autopi.cmd
```

`pi.cmd` 是兼容入口，`pi-wake.cmd` 用于向已经在线的 AutoPi 会话发送 Wake 事件。

## 9. 更新与卸载

AutoPi 当前是绿色免安装软件：

- 更新：退出旧版本，下载并解压新版本；不要把新旧版本混在同一目录。
- 卸载：退出 AutoPi 后删除整个程序文件夹。
- 会话和模型配置存放在用户数据目录中，删除程序文件夹不会自动删除这些个人数据。

## 10. 常见问题

### 双击没有窗口

确认已经完整解压，并且 `AutoPi.exe` 与 `resources` 目录位于同一文件夹。检查任务管理器中是否已有 AutoPi；它是单实例程序，再次启动会聚焦现有窗口。

### 打开工作区后没有模型可选

进入设置检查服务商/API Key，或使用对应服务商的登录命令。配置完成后重新进入会话。

### AutoPi 无法写入文件

检查工作区是否位于只读、系统保护或需要管理员权限的位置。优先把项目放在自己的文档或代码目录，不建议以管理员身份长期运行 AutoPi。

### 如何确认下载未损坏

在 PowerShell 中进入下载目录后运行：

```powershell
Get-FileHash .\AutoPi-0.84.1-win-x64.zip -Algorithm SHA256
```

把结果与 Release 附带的 `.sha256` 文件比较，二者应完全一致。

### 如何反馈问题

先阅读 [README](../README.md) 的当前边界。确认不是凭据或安全问题后，可到 [GitHub Issues](https://github.com/shoelace66/AutoPi/issues) 提交复现步骤、AutoPi 版本和必要日志。安全问题请按照 [SECURITY.md](../SECURITY.md) 私密报告。
